# İncelemeye hazır Xacpant değişiklikleri

XACPANT_PATCH.diff, bilgisayardaki özgün Bruce kaynağına göre metin değişikliklerini gösterir. CHANGED_FILES.json dosyası değişen/eklenen dosyaların SHA-256 özetlerini içerir.
